# 纪录片策划

先经稳定CLI/MCP发现当前作品、活动包、Schema及同包方法，携带精确WorkRef、management_ref和活动摘要。先读已有工程、来源和意见，不要求作者重复填写对话内容。

固定采访和实际素材 → 逐字引文与入出点 → 并列支持和相反证词 → 问题与主张 → 比较纸上剪辑 → 固定意见返工 → 复核依据并交接制作。

媒体与原始选段只追加，逐字引文核对固定文字来源；入出点必须位于完整回读的真实媒体容器时长内。文本匹配不证明录音说过这些话，timing_note明确对齐依据。证词关系分支持、反证和背景，不按数量判定事实。纸剪固定选段、主张、证词关系和问题组合摘要，旁白标明估时，素材重复出场各有独立ID。新建和主动改动编排须匹配当前摘要，旧编排保留过期；原意见不能默套新稿。MP4检查只核验容器与元数据，不冒充全帧解码或内容认可。

[工作流程](references/workflows.md)解释专业取舍、媒体和接续；[操作地图](references/operations.md)由清单生成。每次保存回读固定修订，未知先get_operation，CAS保留原输入。create_handoff记录阶段依据和下一步。素材可读取不代表获准外发；费用、采纳、定稿及发布按作者确切决定。
