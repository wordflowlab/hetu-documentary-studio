# Skill与机器接续

包内hetu-documentary-studio由河图动态发现，不创建Codex插件、独立MCP服务器或客户端工具名。安装和启用后重新读取活动包摘要、capabilities与skills.read；旧能力绑定不得继续使用。业务无需启动桌面。

默认旅程：固定采访和实际素材 → 逐字引文与入出点 → 并列支持和相反证词 → 问题与主张 → 比较纸上剪辑 → 固定意见返工 → 复核依据并交接制作。先读已有工程、固定作品及意见，不新建另一份演示工程替代接续。方法由Skill维护，确定性规则由专业后端执行。

媒体与原始选段只追加，逐字引文核对固定文字来源；入出点必须位于完整回读的真实媒体容器时长内。文本匹配不证明录音说过这些话，timing_note明确对齐依据。证词关系分支持、反证和背景，不按数量判定事实。纸剪固定选段、主张、证词关系和问题组合摘要，旁白标明估时，素材重复出场各有独立ID。新建和主动改动编排须匹配当前摘要，旧编排保留过期；原意见不能默套新稿。MP4检查只核验容器与元数据，不冒充全帧解码或内容认可。

每阶段保存并回读固定修订，create_handoff记录依据、目标与未解决问题。其他插件根据实际安装能力独立发现，通过固定专业引用组合。未知先回读，正文采纳、定稿、内容外发与费用按作者确切决定执行。

SKILL.md作为精炼方法入口，references/workflows.md提供专业方法与反例，operations.md从正式清单生成。专业清单由本仓库维护，宿主40只导航动态入口。
