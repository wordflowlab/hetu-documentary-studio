# 用户用例与验收矩阵

| 用例 | 正向 | 反向及边界 |
| --- | --- | --- |
| 01 原话与实际媒体 | 准确文字引文和真实入出点分开核验 | 文字匹配不证明语音真实，错字和越界拒绝 |
| 02 媒体完整性 | 逐块回读完整文件及摘要后解析WAV或MP4容器 | 截断、零时长、错误引用和不支持格式拒绝 |
| 03 不同证词 | 同一主张保留支持、反证和背景 | 不以支持数认证事实或隐藏反证 |
| 04 纸上剪辑 | 片段重复出场、旁白估时和未知素材缺口明确 | 不把旁白估时算作已生成片段 |
| 05 依据变化 | 主张关系变化后旧纸剪和意见过期 | 新错误摘要拒绝，不自动重签 |
| 06 局部编排 | 两种结构逐项比较，原选段不可改写 | 不覆盖原话、媒体或其他序列 |
| 07 交付 | 完整纸剪、媒体映射及可读审核本 | 不是成片渲染或授权证明 |
| 09 固定作品 | 小说、独立剧本、独立视频各自获权和读取 | 错作品引用、撤权及错误摘要拒绝 |
| 10 操作恢复 | 同键重放、写后丢回执、旧修订回读 | 同键异参、未知结果不重复落盘 |
| 11 热插拔 | 同连接发现Skill，安装启停卸载重装 | 停用与旧活动绑定拒绝；历史保留 |
| 12 作者审核 | 五页、浅暗、1360／760、键盘及降级 | 空、错误、取消、CAS保留与关闭恢复 |
| 13 组合接续 | 两包固定专业依据接续并准备宿主候选 | 不合并管理权或修改原稿 |
| 14 公开交付 | 固定Tag、双摘要、重新下载安装与官网 | 不覆盖同版本附件或公开私密绑定 |

先执行领域正反例和真实应用单元，再正式制品CLI/MCP逐动作、包内Skill、实际Electron与当前Codex。例子采用原创虚构资料，不冒充真人研究、文献权利或文学品质认证；跨视口检查不等于Windows/Linux专业实机。
