# 产品需求

## 背景与推导

纪录片的叙事来自实际拍摄和采访，却经常在选段、旁白和次序中发生重构。一次性文字方案容易丢失原话、反证、实际素材入出点和删改理由。工程保存原件及不同说法，Agent帮助研究与组织，作者决定怎样讲述。纸上剪辑必须诚实区分实际片段时长和未录旁白估时，不把计划冒充成片。

生成成本和等待时间会变化，但固定作品、历史依据、具体意见与连续审阅仍需长期积累。固定工程避免让模型每轮重建结构；结构化数据与多种阅读方式共用同一专业成果。插件按需安装，让作者提出目标、Agent操作工程、作者在适合的工作面阅读和选择。

## 定义与首版

纪录片策划是河图洛书JS／TS专业插件。把固定采访、不同证词与实际素材选段组织成可复核、可继续修改的纸上剪辑。用户包括独立作者、编辑与外部Agent。默认旅程：固定采访和实际素材 → 逐字引文与入出点 → 并列支持和相反证词 → 问题与主张 → 比较纸上剪辑 → 固定意见返工 → 复核依据并交接制作。

首版包含完整专业维护、准确来源回读、并行方案、局部备选、意见、改稿影响、上下文、固定交接、JSON／Markdown／HTML工程及专业阅读本。功能必须经机器入口执行，作者可以自然语言提出目标，也保留人工优化入口。

## 边界

纪实写作维护文章核实，本包拥有采访素材选段和纪录片叙事纸剪；视听制作拥有实际剪辑与成片。本包不联系受访者、不认证事实、不生成或发布影片、不按叙事推断拍摄及传播权。正文、正式设定、素材、采纳与定稿由宿主和作者掌握，不另建数据库、模型渠道或内部Agent。

成功以真实创作、审阅、返工及下一轮接续为准，安装、动作数或文件存在都不足以代表完成。开发与验收状态只由08维护。
